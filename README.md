# giftafonta.github.io
A personal portfolio website showcasing my data analysis projects — from raw data cleaning through to dashboards and business recommendations.
I'm a data analyst working with retail, sales, and operational datasets. This site collects the projects I've built while learning and practising — each one starts with a messy dataset and ends with something a business could actually act on.

Every project here includes the full workflow: data cleaning, exploratory analysis, visualisation, and a written summary of what the numbers mean.
